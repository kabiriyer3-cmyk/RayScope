## RayScope {{NAME}}

VPN-клиент на Xray-core с расширенной диагностикой для Android, Windows и Linux.

### Что нового

- **Прокси как серверы**: SOCKS5 и HTTP(S). Подходят ссылки `socks5://логин:пароль@адрес:порт`, `http://…`, `https://…`, `socks://` из v2rayN, телеграмные `tg://socks` и `t.me/socks`, а также списки из прокси-магазинов: `адрес:порт`, `адрес:порт:логин:пароль`, `логин:пароль@адрес:порт`. Строки без схемы считаются SOCKS5, для HTTP допишите `http://`. Пинг, проверка реального IP, фильтр по стране и «Поделиться» работают так же, как с обычными серверами.
- **Android**: в режиме VPN DNS для прокси идёт по TCP, поэтому HTTP-прокси и SOCKS5 без UDP не оставляют без интернета.
- **Linux**: та же программа, что на Windows. Системный прокси в GNOME и KDE, режим TUN (пароль администратора спросит система), автозапуск, трей там, где он есть.
- **Реальный IP выхода** (1.2.20): проверка показывает, в какой стране сервер выпускает в интернет на самом деле, и фильтр по этой стране.

**Android, какой APK скачать:**
- `arm64-v8a`: почти все современные телефоны
- `armeabi-v7a`: старые 32-битные устройства
- `x86_64` / `x86`: эмуляторы и Chromebook
- `universal`: подойдёт куда угодно (самый тяжёлый)

**Windows 10 / 11 (x64):**
- `RayScope-Setup-{{NAME}}.exe`: установщик (рекомендуется). Права администратора не нужны, ярлыки появятся на рабочем столе и в Пуске, удаление через «Приложения».
- `RayScope-{{NAME}}-windows-x64-portable.zip`: портативная версия, распакуйте и запустите `RayScope.exe`.

SmartScreen может предупредить, потому что у файла нет платной подписи: «Подробнее», затем «Выполнить в любом случае».

**Linux (x64):**
- `rayscope_{{NAME}}_amd64.deb`: Debian, Ubuntu, Mint и родственники, `sudo apt install ./rayscope_{{NAME}}_amd64.deb`.
- `RayScope-{{NAME}}-linux-x64.tar.gz`: любой дистрибутив, распакуйте и запустите `./rayscope`, в меню добавит `./install.sh`.

Java и ядро Xray уже внутри. Контрольные суммы в `SHA256SUMS.txt`.
